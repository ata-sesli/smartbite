## Corrected End-to-End Workflow

The complete SmartBite system operates as follows:

1. The user opens the SmartBite React Native / Expo mobile application and starts a scan from the product capture screen.
2. The mobile application captures a product image, attaches optional product metadata, and sends the image to the SmartBite backend API over HTTP.
3. For standard operation, the app sends the request to the backend scan-creation endpoint, which stores the uploaded image, creates a scan record, and places the job into the asynchronous processing queue.
4. The backend worker retrieves the queued scan and runs the AI pipeline. In the first AI stage, the YOLO-based detector identifies the expiry-date region on the product packaging rather than merely the whole product region.
5. The detected expiry region is cropped and passed through preprocessing steps such as contrast enhancement, thresholding, denoising, and variant generation to improve OCR robustness.
6. The processed crop is then passed to the PP-OCRv5 recognition pipeline, which returns recognized text candidates together with confidence information.
7. Instead of trusting only the single top-confidence OCR string, the parsing stage evaluates the recognized text candidates, applies date-pattern matching and normalization rules, and selects the most plausible canonical expiry date.
8. The urgency-classification stage compares the parsed expiry date with the current date, computes the remaining time, and assigns an application-level label such as `safe`, `expiring_soon`, `expired`, or `manual_review_required`.
9. The backend stores the scan result, parsed date, classification outcome, and alert-related state in the application database.
10. The mobile application retrieves the result from the backend and updates the dashboard by showing the recognized expiry date, the urgency badge, and the scan history entry.
11. If the resulting classification requires a reminder or warning, the backend creates an alert event. When the user has a registered push token, the notification layer sends a push notification through Firebase Cloud Messaging so that the React Native / Expo client can warn the user even when the app is not actively open.
12. In a one-shot analysis mode used for quick testing, the mobile app or internal console may wait for the backend to finish processing immediately; however, the underlying AI logic remains the same detection → OCR → parsing → classification pipeline.
